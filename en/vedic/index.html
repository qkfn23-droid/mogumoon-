What is Vedic Astrology?

Vedic astrology (Jyotish) is an astronomical system that began in ancient India about 5000 years ago. In Sanskrit, it means "science of light." Unlike Western astrology, it uses the sidereal system. It features precise analytical frameworks including Nakshatras (27 lunar mansions), Dasha (planetary periods), and Divisional charts.

Frequently Asked Questions

Is Vedic astrology different from Western astrology?

Yes, Vedic uses the sidereal system while Western uses the tropical system. There is about a 23-degree difference.

What if I don't know my birth time?

A basic chart can still be generated without birth time. However, accurate house placements and Lagna (ascendant) require birth time.
